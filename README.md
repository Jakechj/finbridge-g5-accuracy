# FinBridge G5 — AI 답변 정확도 비교 원자료

한국 상장사 공시 질문 20개를 같은 AI 모델에 두 조건으로 물었다. 웹 검색만 쓴 경우와 FinBridge MCP만 쓴 경우다. 이 저장소에는 질문, DART 원문으로 확인한 정답, 두 조건의 답변, 블라인드 채점이 그대로 들어 있다. 측정일은 2026-11-03이다.

## 결과

| 조건 | 숫자 맞음 | 틀림 | 답 없음 | 정답과 같은 접수번호·원문 URL을 댄 답 |
|---|---|---|---|---|
| FinBridge MCP만 사용 | 20 | 0 | 0 | 20 |
| 웹 검색만 사용(질문당 최대 3회) | 10 | 6 | 4 | 0 |

유형별 맞음(FinBridge / 웹): 최근 30일 주요사항 6/6 · 3/6, 사업보고서 재무 8/8 · 5/8, 정정 전후 3/3 · 1/3, 날짜 기준 3/3 · 1/3.
웹 조건의 오답은 모두 잠정치나 반올림된 기사 값을 쓴 경우였다. 미래 시점 값을 끌어 쓴 오답은 두 조건 모두 없었다.

## 방법

1. 질문 20개는 별도 에이전트가 만들었다. 유형 4종, 대형주 10개와 코스닥 소형주 10개다.
2. 정답은 FinBridge를 쓰지 않고 dart.fss.or.kr 원문을 직접 열어 확인했다. 정답마다 접수번호, URL, 확인 시각을 적었다.
3. 응답자는 서로 다른 에이전트 둘이다. 둘 다 같은 모델이고 질문 파일만 볼 수 있었다. 한쪽은 웹 검색과 웹 페이지 읽기만, 다른 쪽은 FinBridge MCP 도구만 썼다.
4. 채점은 또 다른 에이전트가 했다. 두 답을 X·Y로 가려 어느 조건인지 모른 채 정답과 대조했다. 단위는 환산했고, 원문 표시 단위의 반올림 차이는 맞음으로 봤다.

## 파일

| 파일 | 내용 |
|---|---|
| `data/questions.json` | 질문 20개와 정답(값, 단위, 접수번호, 원문 URL, 확인 시각) |
| `data/answers_A.json` | 웹 검색 조건 답변(검색 횟수 포함) |
| `data/answers_B.json` | FinBridge MCP 조건 답변(도구 호출 수 포함) |
| `data/grade.json` | 블라인드 채점. 각 문항의 X·Y에 숫자 판정(`num`)과 근거 판정(`src`) |
| `data/blind_key.txt` | X·Y가 어느 조건인지(X=B, Y=A) |

## 한계

- 표본은 20문항이고 한 번만 쟀다.
- 질문 작성자는 FinBridge가 다루는 범위를 알고 있었다. 질문은 DART 원문으로 확인할 수 있는 것으로만 이뤄져 FinBridge 쪽에 유리한 구성이다.
- 응답자는 실제 사용자 화면이 아니라 같은 모델로 돌린 에이전트다. 웹 조건의 검색 3회 제한도 실험 설계상의 값이다.
- 반올림을 조 단위까지 넓게 인정하면 웹 조건이 1~2문항 더 맞는다(7번, 19번).
- 18번 정답(신한지주 지배기업 순이익)은 원문 재확인이 필요하다. 바뀌더라도 웹 조건 판정만 달라진다.
